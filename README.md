# Работа мечты

Учебное веб-приложение курса job4j: закрепление основ разработки веб-приложений на Java с опорой на Spring Boot и Spring MVC. Подробный разбор самого Spring вынесен в отдельный блок курса; здесь акцент на архитектуре веб-приложения: модели, слои, взаимодействие пользователей и структура кода.

## Предметная область

- Кандидаты — публикуют резюме, откликаются на вакансии.
- Кадровики — публикуют вакансии, приглашают кандидатов на открытые позиции.

## Технологии

Java 21, Spring Boot 3.4, Thymeleaf для страниц, Bootstrap для вёрстки. Собираю всё через Maven. Checkstyle подключен — при сборке проверяет стиль кода.
